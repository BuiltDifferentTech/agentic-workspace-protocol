# Agent Instructions

This repository defines and maintains the **Agentic Workspace Protocol (AWP)** — the specification and templates published by this project.

## Working on the specification itself

[`templates/.agents/docs/design-document.md`](templates/.agents/docs/design-document.md) is the source of truth for what AWP *is*. Treat it as human-provided context: do not reorganize, rewrite wholesale, or silently change its meaning. Propose changes explicitly and explain the reasoning in the pull request.

The `templates/` directory contains the copyable starter kit that other projects use to adopt AWP. When the specification changes, check whether the rest of `templates/` needs to change to match.

## Before finishing

1. Verify the change (e.g. templates still match the spec, links still resolve).
2. Confirm `README.md` and `CONTRIBUTING.md` are still consistent with what changed.
